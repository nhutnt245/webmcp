The flight app inside an iframe, with allow="tools"

The page you are reading is the parent (port 4174). The framed page below is the child: the same flight app that npm start serves on port 4173. The two ports make two different origins.

The tools Permissions Policy defaults to self, so a cross-origin iframe cannot use WebMCP unless the parent delegates it with allow="tools".

<iframe src="http://127.0.0.1:4173/" allow="tools"></iframe>

To test it, open DevTools and choose the child frame (127.0.0.1:4173) in the console's context selector. See the README for the steps.
